# v3.2.0 - Stop Order Triggering and Reference Price Support

Order Service now activates pending `STOP` and `STOP_LIMIT` orders from latest reference prices.

Added:

- Additive `013` migration with `reference_prices` and stop-trigger tracking columns on `orders`.
- Market Data emits `market.price.updated` events; Order Service consumes the market topic and upserts reference prices.
- Stop-trigger worker with bounded polling, stale-price protection, row locking, idempotent activation, and graceful shutdown.
- `STOP -> MARKET` and `STOP_LIMIT -> LIMIT` activation that reuses the existing matching flow.
- Same-transaction `order.triggered` history and transactional outbox writes.
- Prometheus metrics and `GET /internal/stop-trigger/status`.
- Event schemas for `market.price.updated` and `order.triggered`.
- Local demo script and stop-order triggering documentation.

Risk behavior:

- Triggered orders use the pre-trade risk decision made when the original stop order was placed. v3.2.0 does not perform a second activation-time risk call.

Known limitations:

- Reference prices are latest snapshots by tenant/symbol and are not venue-specific NBBO marks.
- The market price consumer accepts legacy tick event names while Market Data standardizes on `market.price.updated`.
