# v3.5.0 - Real OAuth2/OIDC Authentication, JWT Validation, And Service Authorization

v3.5.0 hardens authentication around JWKS-validated JWTs, normalized identity propagation, service auth, and tenant-aware backend trust.

Highlights:

- API Gateway validates RS256 JWTs with JWKS, issuer, audience, expiry, not-before, `kid`, and algorithm allowlist checks.
- Gateway strips spoofed `X-TradeOps-*` headers and forwards normalized trusted identity headers.
- Identity Service exposes OIDC discovery, JWKS, and `/api/v1/auth/token` for local demos.
- Order, Portfolio, and Audit services trust gateway identity headers only with valid service auth.
- Internal status endpoints in Order and Portfolio require service auth.
- Added bounded Prometheus auth metrics and `auth.decision.v1` event schema.
- Added Helm and Docker Compose auth configuration plus `scripts/demo-oidc-auth-rbac.sh`.

Known limitations:

- Local service auth is a shared-secret mechanism for demos; production should use mTLS or workload identity.
- Auth decision schema is added, but high-volume allow-event emission remains a follow-up integration.
- Python risk/strategy services retain their existing JWT/RBAC scaffolding in this release slice.
